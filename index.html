    About this dashboard

    A simple, fast weather dashboard for Sri Lanka. It shows current conditions, the next 24 hours, a 7-day outlook, air quality, marine conditions and an interactive map — with minimal navigation and no account needed.

    How to use

    • Dashboard — current weather, hourly, 7-day, air quality and marine for the selected place.
    • Map — tap a marker to switch location.
    • Cities — browse major cities or your favourites.
    • Search — type any Sri Lankan town/village. Use 📍 for your current location. Toggle °C / °F in the header.

    Data sources (accurate & free)

    • Open-Meteo Forecast API — current, hourly and daily weather. Data from ECMWF IFS, GFS, ICON and other numerical weather prediction models via Open-Meteo. Free, no API key, CC-BY 4.0.
    • Open-Meteo Geocoding API — resolves Sri Lankan place names to latitude/longitude.
    • Open-Meteo Air Quality API — US AQI, PM2.5, PM10, O₃, NO₂ and dust from the Copernicus Atmosphere Monitoring Service (CAMS).
    • Open-Meteo Marine Weather API — wave height, period, swell and sea-surface temperature for coastal waters.
    • Department of Meteorology, Sri Lanka — official weather warnings, monsoon / cyclone advisories and climatology. For official warnings and safety decisions, always check meteo.gov.lk.
    • OpenStreetMap map tiles via Leaflet.

    Notes & limitations

    • Times are shown in local time (Asia/Colombo, UTC+5:30) as returned by the API’s timezone.
    • Marine data uses the nearest coastal grid cell — it may be offshore for inland cities; treat inland “marine” values as indicative only.
    • Forecasts are model outputs and can change. Check the Department of Meteorology for official alerts, especially during monsoon seasons (Yala: May–September, Maha: October–February).
    • This is a static web app. No signup, no tracking beyond standard GitHub Pages / CDN hosting. Favourites are stored in your browser (localStorage).
