    ප්‍රියතම නගර

    තවම ප්‍රියතම නගර නැත. නගරයක් විවෘත කර “☆ ප්‍රියතම” තට්ටු කරන්න. මෙම උපාංගයේ පමණක් සුරකිනු ලැබේ.

    මෙම උපකරණ පුවරුව ගැන

    SSS Sea Food Suppliers සඳහා නිර්මිත ශ්‍රී ලංකා කාලගුණ උපකරණ පුවරුවක්. දැනට තත්ත්වය, ඉදිරි පැය 24, දින 7 අනාවැකිය, වායු ගුණාත්මකභාවය, මුහුදු තත්ත්වය සහ අන්තර්ක්‍රියාකාරී සිතියමක් — ගිණුමක් නොමැතිව. ධීවර කටයුතු සහ මුහුදු ගමන් සඳහා මුහුදු තත්ත්ව දත්ත විශේෂයෙන් ප්‍රයෝජනවත්.

    භාවිතා කරන ආකාරය

    • මුල් පිටුව — තෝරාගත් ස්ථානයේ දැනට කාලගුණය, පැයක අනාවැකිය, දින 7 අනාවැකිය, වායු ගුණාත්මකභාවය සහ මුහුදු තත්ත්වය.
    • සිතියම — ස්ථානය මාරු කිරීමට සලකුණක් තට්ටු කරන්න.
    • නගර — ප්‍රධාන නගර හෝ ඔබේ ප්‍රියතම නගර බලන්න.
    • සෙවීම — ඕනෑම ශ්‍රී ලාංකික නගරයක් හෝ ගමක් ටයිප් කරන්න. 📍 මගින් ඔබේ වත්මන් ස්ථානය භාවිතා කරන්න. ඉහළින් °C / °F මාරු කරන්න.

    දත්ත මූලාශ්‍ර (නිවැරදි සහ නොමිලේ)

    • Open-Meteo Forecast API — දැනට, පැයක සහ දෛනික කාලගුණය. ECMWF IFS, GFS, ICON ඇතුළු අනාවැකි ආකෘතිවලින් Open-Meteo හරහා. නොමිලේ, API යතුරක් නොමැතිව, CC-BY 4.0.
    • Open-Meteo Geocoding API — ශ්‍රී ලාංකික ස්ථාන නාම අක්ෂාංශ/දේශාංශ බවට හරවයි.
    • Open-Meteo Air Quality API — US AQI, PM2.5, PM10, O₃, NO₂ සහ දූවිලි, Copernicus Atmosphere Monitoring Service (CAMS) වෙතින්.
    • Open-Meteo Marine Weather API — රැලි, ඉදිමුම්, සුළං රැලි, මුහුදු ජල උෂ්ණත්වය, මුහුදු මට්ටම (වේලා ඇතුළුව) සහ සාගර ධාරා (වේගය හා දිශාව). ධාරා හා වේලා MeteoFrance SMOC වෙතින්; රැලි MFWAM වෙතින් — Copernicus Marine හරහා.
    • ශ්‍රී ලංකා කාලගුණ විද්‍යා දෙපාර්තමේන්තුව — නිල අනතුරු ඇඟවීම්, මෝසම් / චක්‍රවාත උපදෙස්. නිල අනතුරු ඇඟවීම් සහ ආරක්ෂාව සඳහා සැමවිටම meteo.gov.lk බලන්න.

    • මුහුදු දත්ත සඳහා වෙරළට ආසන්න සාගර ඛණ්ඩාංකයක් භාවිතා කරයි. ගොඩබිම් නගර සඳහා එය ආසන්න අගයක් පමණි. මෙම දත්ත නාවික සංචාලනයට නොවේ — නාවික ඇල්මනැක් සහ නිල අනතුරු ඇඟවීම් භාවිතා කරන්න.
    • අනාවැකි ආකෘතිවල ප්‍රතිඵල වන අතර වෙනස් විය හැක. විශේෂයෙන් මෝසම් කාලවලදී (යල: මැයි–සැප්තැම්බර්, මහ: ඔක්තෝබර්–පෙබරවාරි) නිල අනතුරු ඇඟවීම් සඳහා කාලගුණ විද්‍යා දෙපාර්තමේන්තුව බලන්න.
